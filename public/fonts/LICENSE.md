# Font licenses

All fonts in this folder are latin-subset WOFF2 files downloaded from Google Fonts and
self-hosted for performance. Each is licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/),
which allows bundling and redistribution with software.

|---|---|---|
| `bricolage-grotesque.woff2` | Bricolage Grotesque | https://fonts.google.com/specimen/Bricolage+Grotesque |
| `manrope.woff2` | Manrope | https://fonts.google.com/specimen/Manrope |
| `playfair-display-italic.woff2` | Playfair Display (italic) | https://fonts.google.com/specimen/Playfair+Display |
| `jetbrains-mono.woff2` | JetBrains Mono | https://fonts.google.com/specimen/JetBrains+Mono |
